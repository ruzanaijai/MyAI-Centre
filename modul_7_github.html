Modul 7

Menerbitkan Website

Panduan lengkap membawa laman web anda ke internet (Live) secara percuma menggunakan GitHub Pages.

Tatal ke bawah untuk bermula ↓

1

Daftar Akaun GitHub

Langkah pertama adalah mencipta profil pembangun anda di platform GitHub.

  • Layari laman web rasmi github.com.
  • Klik butang "Sign Up" di penjuru kanan atas.
  • Masukkan e-mel, cipta kata laluan, dan pilih Username yang sesuai.
  • Sahkan akaun melalui e-mel yang dihantar.

💡 Tips Penting:

Pilih Username (nama pengguna) yang kemas dan profesional (contoh: ruzanaijai) kerana ia akan menjadi sebahagian daripada pautan (link) laman web anda nanti.

2

Setup Repository

Repository (atau Repo) adalah seperti sebuah 'folder' khas di internet untuk menyimpan semua fail laman web anda.

Langkah 2.1

Di halaman utama GitHub, cari dan klik butang hijau "New" atau ikon tambah (+) dan pilih "New repository".

Langkah 2.2

Beri nama pada repo anda di ruangan Repository name (Contoh: MyAI-Centre). Jangan guna jarak (space).

Langkah 2.3

Pastikan tetapan diletakkan sebagai "Public". Kemudian, skrol ke bawah dan klik butang "Create repository".

3

Muat Naik & Edit Fail

Cara Masukkan Fail

  1. Di halaman repo anda, klik pautan "uploading an existing file".
  2. Tarik dan lepas (drag & drop) fail index.html (dan fail slaid) dari komputer anda.
  3. Skrol ke bawah dan klik butang hijau "Commit changes" untuk menyimpan fail.

Cara Edit Kod Fail

  1. Di senarai fail repo, klik pada nama fail yang ingin diubah.
  2. Klik ikon pensel ✏️ (Edit) di penjuru kanan atas.
  3. Buat perubahan pada kod teks anda.
  4. Klik butang hijau "Commit changes" untuk menyimpan.
4

Melancarkan Website (Live!)

Langkah 4.1

Klik tab Settings (ikon gear ⚙️) di menu atas repository anda.

Langkah 4.2

Lihat menu di sebelah kiri, skrol ke bawah dan klik pada Pages.

Langkah 4.3

Di bahagian Branch, tukar kotak dari "None" kepada "main".

Langkah 4.4

Klik Save. Tunggu 1-2 minit. Laman web sedia dilayari!
