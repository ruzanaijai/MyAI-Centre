Struktur Pembelajaran

7 Modul komprehensif dari asas hingga penerbitan.

Modul 1

Asas AI (AI Basic)

Pengenalan kepada teknologi AI Generatif, pemahaman terma penting (LLM, GPT, dll), dan bagaimana AI membantu automasi tugasan harian dan kerja pembangunan web.

Modul 2 (Klik untuk lihat slaid)

Seni Prom (Prompt Basic)

Koleksi formula prom spesifik (berinspirasikan gaya Prompt Academy) untuk menjana kod laman web tepat, merangka struktur menu (UI/UX), dan menghasilkan kandungan teks korporat.
Modul 3

Asas Web

Pemahaman ringkas tentang anatomi laman web. Kenali peranan struktur HTML5, asas JavaScript untuk interaktiviti, dan penggayaan rekaan menggunakan CSS.

Modul 4

Bina Web dengan Gemini

Panduan step-by-step berinteraksi dengan Google Gemini. Dari prompt awalan, proses debugging kod yang dijana, sehingga mendapat hasil kod lengkap yang berfungsi.

Modul 5

Menentukan Objektif

Teknik merangka hala tuju web anda. Ketahui perbezaan komponen yang perlu ada untuk Landing Page, Web Portfolio peribadi, atau profil Perniagaan (Corporate).

Modul 6

Layout & Copywriting

Menggunakan AI sebagai *copywriter* dan *designer*. Menjana susun atur yang menarik secara visual dan penulisan yang meyakinkan (persuasif) untuk pelawat web.

Modul 7

Menerbitkan Website (Publish)

Pelajari cara *hosting* laman web anda secara percuma! Panduan menaik taraf fail ke Github Pages, Vercel, Google Site, atau perkhidmatan percuma yang lain.
